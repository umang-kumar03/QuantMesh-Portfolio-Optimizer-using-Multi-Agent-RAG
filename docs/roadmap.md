# Roadmap

## Delivered

- Existing offline dashboard, strict CSV input, optimization and holdout analytics.
- Benchmark, transaction-cost accounting, interactive risk charts and safe reports.
- Deterministic specialist reports and cited methodology retrieval.
- Alpha Vantage adjusted historical adapter, durable cache, shared quotas, stale and
  synthetic fallback, visible provenance and explicit fetch actions.
- Optional consented OpenAI/Groq explanations with validated citation identity/quotes.
- Provisioned private accounts, scrypt, expiring/revocable sessions, login throttling,
  transactional legacy migration and owner-isolated journal access.
- Numerical, contract, boundary, security and UI tests, dependency audit, CI, non-root
  images, private deployment preparation and an offline Docker-build fallback.

## Remaining increments

1. Verify licensed provider/model requests in the deployment account after configuring
   credentials, account entitlements, outbound access and a paid-request budget.
2. Walk-forward research with cost-aware rebalancing, turnover and locked final holdouts.
3. Licensed external financial-document retrieval with provenance and evaluation sets;
   stronger semantic entailment and prompt-injection evaluation for generated explanations.
4. Enterprise OIDC/MFA, owner-scoped PostgreSQL, audited administration, managed backups,
   per-user provider billing and multi-replica operations when scale requires them.
5. Stress scenarios, factor analysis, robust optimization and cost-aware frontiers.

Public deployment requires the owner's separate approval. GitHub delivery status,
actual tests and unverified integrations are reported separately from this roadmap.
